# Medieval RPG — The Ashvale Trial

A **playable, self-contained medieval fantasy RPG prototype** built with **C++17 + SDL3 + CMake**, compatible with **GCC / MinGW-w64**. The first milestone focuses on a working gameplay loop, rather than external art assets.

## Features (v0.1)

- 960 × 640 top-down medieval village, houses, inn, trees, stone well, dirt roads and stream
- Armored knight controlled with WASD; 8 goblins with basic pursuit AI
- Directional melee combat and cooldown, enemy health indicators
- Collision against buildings, trees and map bounds
- Health / kill counter HUD, win / game-over screens, restart
- Delta-time movement and simple deterministic procedural decoration
- Pure C++ logic unit tests (CTest); no SDL_ttf or downloadable assets needed

## Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Space | Sword attack (face enemy; attack range ~66px) |
| R | Restart |
| Esc | Quit |

Defeat **8 goblins** without losing all your HP to win.

## Build on Windows (MSYS2 MinGW-w64 GCC)

Open the **MSYS2 UCRT64** terminal and install dependencies:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-SDL3
```

Then from the project directory:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
./build/medieval_rpg.exe
```

Use the same **UCRT64** shell to run the game so SDL3 DLLs are in PATH. If launching the EXE outside MSYS2, ensure SDL3.dll and any required MinGW runtime DLLs are available beside it or on PATH.

## Manual SDL3 MinGW download (Windows)

Download `SDL3-devel-3.4.2-mingw.zip` from the official SDL GitHub release, extract the `x86_64-w64-mingw32` folder and point CMake to it:

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH="D:/Libraries/SDL3/x86_64-w64-mingw32"
cmake --build build
.\\build\\medieval_rpg.exe
```

Make sure `SDL3.dll` is on PATH or beside the game executable.

## Build on Linux (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install build-essential cmake pkg-config libsdl3-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j
ctest --test-dir build --output-on-failure
./build/medieval_rpg
```
